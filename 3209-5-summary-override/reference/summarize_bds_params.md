# Summarize the Parameters of a BDS Dataset

Summarize the Parameters of a BDS Dataset

## Usage

``` r
summarize_bds_params(dataset, unit_vars, unit = "subjects")
```

## Arguments

- dataset:

  A data frame with a `PARAMCD` variable

  Default value

  :   none

- unit_vars:

  The variables subjects, or devices, are identified by

  Default value

  :   none

- unit:

  The name of the column they are counted in, `"subjects"` or
  `"devices"`

  Default value

  :   `"subjects"`

## Value

The `params` element described in
[`summarize_bds()`](https:/pharmaverse.github.io/admiral/3209-5-summary-override/reference/summarize_admiral_df_type.md):
a data frame with one row per `PARAMCD`.
