# Print the Checks of a Summary

Prints each failed check as its own bullet, and the passed checks
together as a single bullet. A check whose element is not in `d` –
because the variables it needs are not in the dataset – was not run and
is not mentioned.

## Usage

``` r
print_summary_checks(d, checks)
```

## Arguments

- d:

  The `details` element of a `summary_admiral_df` object. Each check is
  read from `d[[name]]`, the number of failures, and fails if it is
  greater than zero.

  Default value

  :   none

- checks:

  A named list with an element per check, named as in `d`. Each element
  is a list with `failed`, a cli message evaluated in the calling
  function, and `passed`, a plain character scalar.

  Default value

  :   none

## Value

No return value, called for side effects
