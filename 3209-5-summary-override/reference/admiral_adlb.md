# Lab Analysis Dataset

An example of lab analysis dataset

## Usage

``` r
admiral_adlb
```

## Format

An object of class `admiral_df` (inherits from `tbl_df`, `tbl`,
`data.frame`) with 330 rows and 115 columns.

## Source

Derived from the `adlb` template, then further filtered due to dataset
size by the following USUBJIDs: 01-701-1015, 01-701-1023, 01-701-1028,
01-701-1033, 01-701-1034, 01-701-1047, 01-701-1097, 01-705-1186,
01-705-1292, 01-705-1310, 01-708-1286

The dataset is an
[`admiral_df()`](https:/pharmaverse.github.io/admiral/3209-5-summary-override/reference/admiral_df.md)
with its name (`"ADLB"`), class (`"BDS"`), and key variables (`STUDYID`,
`USUBJID`, `PARAMCD`, `ADT`, `AVISITN`, `VISITNUM`) stored.
