# Count the Groups with More than One Baseline Record

Count the Groups with More than One Baseline Record

## Usage

``` r
count_multiple_baselines(dataset, by)
```

## Arguments

- dataset:

  A data frame with an `ABLFL` variable

  Default value

  :   none

- by:

  The variables a baseline record is unique within

  Default value

  :   none

## Value

The number of combinations of `by` with more than one `ABLFL == "Y"`
record, each counted once however many it has.
