# Summarize the Distribution of a Numeric Variable

Summarize the Distribution of a Numeric Variable

## Usage

``` r
summarize_distribution(x)
```

## Arguments

- x:

  A numeric vector

  Default value

  :   none

## Value

A named numeric vector with the elements `median`, `min`, and `max`, or
`NULL` if `x` has no non-missing values.
