# Subject Level Analysis Dataset

An example subject level analysis dataset

## Usage

``` r
admiral_adsl
```

## Format

An object of class `admiral_df` (inherits from `tbl_df`, `tbl`,
`data.frame`) with 306 rows and 54 columns.

## Source

Derived from the `dm` and `ds` datasets using `{admiral}`
(<https://github.com/pharmaverse/admiral/blob/main/inst/templates/ad_adsl.R>)

The dataset is an
[`admiral_df()`](https:/pharmaverse.github.io/admiral/3209-5-summary-override/reference/admiral_df.md)
with its name (`"ADSL"`), class (`"ADSL"`), and key variables
(`STUDYID`, `USUBJID`) stored.
