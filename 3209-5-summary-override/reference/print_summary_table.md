# Print a Table of a Summary as Aligned Text

Prints a header line and one line per row, indented, with character
columns left-aligned and numeric columns right-aligned. Fractional
numbers are shown to 4 significant digits, whole numbers in full, and
missing values as `.`.

## Usage

``` r
print_summary_table(tbl, max_rows = Inf, what = "row")
```

## Arguments

- tbl:

  A data frame

  Default value

  :   none

- max_rows:

  The maximum number of rows to print. The number of rows left out is
  reported below the table.

  Default value

  :   `Inf`

- what:

  What a row is, used to report the rows left out

  Default value

  :   `"row"`

## Value

No return value, called for side effects
